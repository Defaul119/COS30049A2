\textbf{WBS Dictionary}

The full WBS dictionary is provided in Appendix~\ref{app:dictionary} of this report.

The dictionary gives each leaf work package a tangible output, predecessor, duration and owner, applying the Week 2 scope, WBS and dictionary examples (Li n.d.d, slides 3–11). The summary below uses the same codes as the WBS chart (Figure~\ref{fig:wbs}) and Gantt chart (Figure~\ref{fig:gantt}); descriptions, inputs, resources, effort and acceptance criteria for every package are in Appendix~\ref{app:dictionary}. Where a package lists more than one owner, the role lead named in Section 3 is accountable: the Data and ML lead (Cao Tri Tran) for 1.2.1–1.2.7, the UX and web lead (Minh Khang Nguyen) for 1.4.4, and the leader (Cam Dan Bui) for 1.1.1 and 1.1.7.
